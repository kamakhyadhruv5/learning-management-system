# LMS Platform (React + Vite + Tailwind CSS)

A modern, responsive Learning Management System frontend application built with **React**, **Vite**, **Tailwind CSS**, and **React Router DOM**.

## 🧭 Routes Overview

| Route | Page | Description |
|---|---|---|
| `/` | Landing Page | Approved hero with illustration, metrics, and feature cards |
| `/courses` | Courses Catalog | Search, category filtering, and responsive course cards |
| `/courses/:id` | Course Details | Comprehensive syllabus, instructor info, and enrollment |
| `/about` | About Page | Platform mission, student/instructor/admin feature breakdowns |
| `/contact` | Contact Page | Interactive contact form and headquarters information |
| `/role` | Role Selection | Role selector for Student, Instructor, and Administrator |
| `/login` | Login Page | Pixel-perfect login with role selection and quote decoration |
| `/signup` | Sign Up Page | Form validation, role assignment, and localStorage persistence |
| `/student/dashboard` | Student Dashboard | Pixel-perfect student learning dashboard |
| `/student/courses` | My Courses | Enrolled courses listing with progress tracking |
| `/student/progress` | My Progress | In-depth learning analytics, breakdown, and milestones |
| `/student/quizzes` | Quizzes | Upcoming and completed quizzes with scores |
| `/student/certificates` | Certificates | Digital credentials and certificates download |
| `/student/messages` | Messages | Direct instructor messages and announcements |
| `/student/settings` | Settings | Profile preferences and display name settings |
| `/instructor/dashboard` | Instructor Dashboard | Pixel-perfect instructor portal matching reference |
| `/instructor/courses` | Authored Courses | Published and draft courses management |
| `/instructor/courses/add` | Add Course | Course publishing workflow |
| `/instructor/courses/manage` | Course Management | Student submissions, ratings, and course status |
| `/admin/dashboard` | Admin Console | Platform administration and system metrics |
